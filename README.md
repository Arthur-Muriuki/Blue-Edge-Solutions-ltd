# Blue Edge Solutions Limited | IT Infrastructure & E-Commerce Platform

An enterprise-grade website and web application for Blue Edge Solutions Limited featuring IT service offerings, dynamic hardware shop, slide-out cart drawer, automated order ticketing, and real-time administrative order management.

---

## Key Features

* ** Interactive Hardware Shop:** Instant "Add to Cart" toast notifications and dynamic side-drawer cart calculations.
* ** Automated Ticket Generation:** Converts cart checkouts into unique order reference tickets (e.g., `BES-XXXXXX`).
* ** WhatsApp Checkout Integration:** Pre-formats customer WhatsApp messages with unique ticket tracking links.
* ** Printable Receipts:** Interactive client ticket pages (`ticket.php`) with real-time status updates and print options.
* ** Staff Admin Dashboard:** Secured admin control panel (`admin/index.php`) for live status toggling (`PENDING`, `COMPLETED`, `CANCELLED`) and inventory management.
* ** Self-Healing DB Schema:** Automatic database table initialization (`orders` and `order_items`) on checkout execution.

---

##  Tech Stack

* **Backend:** PHP 8.x (PDO / MySQL)
* **Frontend:** HTML5, CSS3, Vanilla JavaScript (ES6+), Phosphor Icons
* **Database:** MySQL / MariaDB
